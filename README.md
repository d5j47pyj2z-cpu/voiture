# Mes Véhicules — Carnet d'entretien
Application PWA pour suivre les véhicules personnels.
Fonctions : véhicules, entretien, nettoyage intérieur/extérieur, dépenses, factures PDF/photos, échéances et alertes.
Les données sont enregistrées localement dans le navigateur. Faire des sauvegardes régulières.
Déploiement : déposer tout le contenu de ce dossier dans un dépôt GitHub puis activer GitHub Pages sur la branche main.
