# Mes Véhicules — Carnet d'entretien personnel

Application PWA mobile pour suivre les véhicules personnels.

## Fonctions
- Véhicules
- Carnet d'entretien
- Nettoyage intérieur / extérieur avec fréquence
- Dépenses
- Factures PDF / photos
- Échéances et alertes
- Sauvegarde locale dans le navigateur
- Fonctionnement hors connexion après installation

## Correction iPhone
La version corrigée réinitialise le défilement des fenêtres de formulaire et gère correctement la Safe Area iPhone. Les formulaires longs restent accessibles du début à la fin.

## Installation avec GitHub Pages
1. Mets le contenu de ce dossier dans ton dépôt GitHub.
2. Va dans **Settings → Pages**.
3. Choisis **Deploy from a branch**.
4. Sélectionne **main** et **/(root)** puis enregistre.
5. Ouvre l'adresse GitHub Pages de ton dépôt.
6. Sur iPhone : **Partager → Sur l'écran d'accueil**.

Les données restent stockées localement sur l'appareil. Pour les factures/photos, fais des sauvegardes régulières.
